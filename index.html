Los datos se guardan en este navegador. Exporta el CSV para tener copia de seguridad o usarlo en otro dispositivo. Sombreadas: las vueltas que cuentan para el HCP SACE.

Guardar en GitHub

El archivo de datos queda en tu repositorio. Si el repositorio es público, cualquiera podría verlo. El token se guarda solo en este navegador, nunca en el archivo.

Cómo crear el token
  1. En github.com: tu foto → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. En Repository access elige Only select repositories y marca solo tu repositorio de golf.
  3. En Permissions → Repository permissions pon Contents: Read and write.
  4. Genera el token, cópialo y pégalo arriba. No lo compartas con nadie.
